# 每轮 system 段（环境注入 + 前缀缓存）— 行为契约

## 目标

模型**本来不知道**的事（当天日期、工作目录、可写范围、工具用法、记忆索引）需要注入 —— 否则模型会猜错日期、往错目录写文件、或用错工具。
**同时**：注入不得破坏模型侧的前缀缓存（prompt/kv cache）。

## 前缀缓存规则（硬约束）

前缀缓存（tools → system → messages 逐段匹配）下，**易变内容出现在前缀中，它之后的一切都要重算**。因此：

| # | 规则 | 防的问题 |
|---|---|---|
| **R1** | 时间粒度**只到天**（`YYYY-MM-DD` + 星期），**禁止时分秒** | 带秒时间戳让**每次请求**前缀全废（最致命） |
| **R2** | 环境段 + 记忆段按 **agent turn 级快照**构建**一次**，turn 内所有模型请求复用**同一份字节** | 一个 turn 内模型请求 N 次（工具循环），若每次现算且内容有变（如 agent 中途 `remember` 改了索引）→ turn 内反复失效 |
| **R3** | 排列顺序严格 **稳定 → 易变**：`tools` → 角色 → 工具要点 → 记忆索引 → pinned 正文 → 日期 | 让可命中的前缀尽可能长；跨天时只丢「日期之后」的部分 |
| **R4** | **禁止**在 system 放每请求变化的字段（请求计数、随机 id、会话时长） | 同类陷阱 |

> R2 与现状冲突：`agent.ts` 现在每次循环迭代都 `unshift(promptExtra)`。plan 协议字符串稳定故无害，但环境/记忆段**必须**改成 turn 级构建一次，不能沿用「每轮现算」。
>
> 已知代价：跨天时仍有一次失效（日期变）。可接受（一天一次）。配置项 `injectDate`（默认 `true`）可关闭，让模型需要时自行 `bash date`——「总结今天的…」这类任务依赖它，默认开。

## 组成

每轮请求的 system 由三部分构成：

| 部分 | 来源 | 是否落盘 | 变化频率 |
|---|---|---|---|
| 会话角色 | `seedSystem`（`chat.ts` 现有那句） | ✓ 落 `system.context` | 建会话时一次 |
| 环境段 | `buildSystemContext(config)` | ✗ 每轮临时 | 配置变时 |
| 记忆段 | 索引 + pinned 正文（见 `memory.md`） | ✗ 每轮临时 | 记忆变更时 |

### 环境段内容

```
今天是 2026-09-17 周四。
工作目录（bash cwd）: /Users/mac/project/ctools
可写范围（file_roots）: /Users/mac/project/ctools, /Users/mac/Documents
工具要点：
- 改文件用 file_edit 精确替换，不要整份重写
- 大文件先 grep 定位，再 file_read 行区间
- 需求不明确用 ask 澄清，不要猜
```

- 工作目录 = `fileRoots[0] || homedir()`（**与 `bash` 命令的 cwd 保持一致**）。
- 日期用**本地时区**，含星期；格式 `YYYY-MM-DD`（R1）。
- 工具要点随工具集变化（未启用的工具不列）。
- `injectDate=false` → 省略第一行。

## 注入位置与顺序

```
tools = registry.toolIds()（按 id 排序，注册表已保证稳定）
messages = [
  <role 系统消息（seedSystem 落盘的那条）>,
  <环境段 + 记忆段 合并成一条 system>,
  ...session.messages(),
]
```

- 环境段与记忆段拼成**一条** system 消息（省 token）。
- `promptExtra`（plan 协议）保持现有 `unshift` 行为——它在 messages 最前，内容在单个 pass 内恒定，不破坏缓存。
- 三段顺序不影响语义，但**必须**稳定 → 易变（R3）。

## 失败与边界

- `fileRoots` 为空 → 显示「（未配置，文件工具不可用）」，不省略整段。
- `buildSystemContext` 抛错 → 回退为只注入会话角色（不阻断请求）。
- 记忆库为空 → 记忆段整段省略（不留空标题）。
- 环境段**不落会话事件** → 历史会话重建时不会看到过期日期。

## 安全约束

- 环境段只含配置与本地事实（路径、日期），**不含任何用户内容**。
- 记忆段受 `memory.md` 的隐私边界约束（索引常驻；正文仅 pinned 常驻）。
