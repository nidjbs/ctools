# cTools 使用指南

面向使用者的完整说明。概览见 [README](../README.md)；架构与开发规范见 [architecture.md](architecture.md) / [AGENTS.md](../AGENTS.md)。

---

## 1. 安装

只支持 **macOS**（系统集成依赖 `pbcopy` / `mdfind` / `sandbox-exec`）。

| 你的 Mac | 下载 |
|---|---|
| Apple 芯片（M 系列） | `cTools-<版本>-arm64-mac.zip` |
| Intel | `cTools-<版本>-mac.zip` |

解压后把 `cTools.app` 拖进「应用程序」。

### 未签名，首次打开需要手动放行

当前版本**未做代码签名与公证**（需要 Apple Developer 账号）。macOS 会以「无法验证开发者」拦截，两种放行方式：

1. 在「应用程序」里**右键点 cTools → 打开**，弹窗里再点一次「打开」（只需一次）
2. 或执行 `xattr -d com.apple.quarantine /Applications/cTools.app`

> **只从你信任的来源下载**。放行未签名应用有风险，不要对来源不明的副本这么做。
> 想从源码自己构建：`npm install && npm run dist`，产物在 `dist/`。

## 2. 第一次使用

cTools **自带模型网关**，无需另外安装任何东西；但它需要**一个模型上游**才能真正干活。

### 2.1 配一个上游

打开设置（任一方式）：

- Launcher 空态列表末尾的 **「⚙️ 设置」** 行
- 菜单栏 **cTools → 设置…**（⌘,）
- 或直接输入 `settings` / `设置` 回车

顶部会出现「**快速开始**」，两条路任选：

**A. 一键用本机 Ollama（推荐）** —— 不需要任何 API key

1. 装好 [Ollama](https://ollama.com) 并拉一个模型（如 `ollama pull qwen2.5`）
2. 点「检测本机 Ollama」→ 选一个模型 → 「使用它」

**B. 手填一个上游**（云端 API）

填 `base_url`、模型名、别名（默认 `chat`），需要密钥时填 `api_key_env`。

> ### ⚠️ `api_key_env` 填的是「环境变量名」，不是密钥本身
>
> 而且 gateway 读的是**它自己进程**的环境变量 —— 从访达/程序坞启动的 app **不会加载 `~/.zshrc`**。所以：
> - 从终端启动（`npm run dev` 或直接运行可执行文件）时，shell 里 `export` 的变量可见
> - 从访达启动时不可见，需要：`launchctl setenv OPENAI_API_KEY 你的密钥`，然后重启 cTools
>
> **用本机 Ollama 则完全绕开这个问题**（它不需要密钥），这也是推荐路径的原因。

### 2.2 选一个可访问目录

回到 Launcher，空态会引导你**选择一个目录**（`file_roots`）。文件工具与 `bash` 都以它为界。

为什么必须由你选：macOS 上 `.app` 的进程工作目录是 `/`，若拿它当默认等于把整个文件系统开放给 agent。
所以 cTools **不猜** —— 未配置时文件类能力直接不可用，并在界面上给出引导。

可以配多个目录：设置 → 偏好 → `file_roots`（每行一个）。

### 2.3 完成

按热键唤起 Launcher，输入 `trans hello` 试试。

## 3. 日常使用

### 3.1 Launcher（热键唤起）

| 你输入 | 会发生什么 |
|---|---|
| 命令前缀，如 `trans`、`find` | 联想命令；回车进入参数态，再回车执行 |
| 命令 + 参数，如 `trans hello world` | 直接执行，结果就地显示（可复制） |
| 自由内容，如 `帮我总结这份 PDF` | 交给 agent → 打开对话窗 |
| `settings` / `设置` | 打开设置 |

- 空输入时显示：**最近会话**（点击即回到那段对话）、常用模板、以及 ⚙️ 设置入口
- 全局热键默认 **⌘⇧Space**（设置里可改）；Launcher 失焦自动收起，`Esc` 逐级收起
- 结果列表**点击即复制**（有「已复制」提示）；文件类结果悬停时浮出「Finder 定位 / 打开」

### 3.2 对话窗（agent）

自由内容回车后进入。可以：

- **看到 agent 在做什么**：工具调用折叠成一行 `▸ 🔧 工具 … · N 次调用`，点开看细节
- **批准危险操作**：agent 想执行 shell、写/删文件时会**停下并弹批准条**，批准才真正执行
- **规划模式**：顶栏「规划」→ agent 先只读调研、产出 4–6 步计划 → 你「批准并执行 / 按反馈重新规划 / 放弃」
- **`/save`**：把一次满意的对话蒸馏成可复用模板，回到首页即成 ⭐ 模板
- **续聊**：关掉窗口后，从 Launcher 的「最近会话」回到任意历史对话；「＋ 新会话」随时另起

### 3.3 长期记忆

对话里让 agent「记住…」，它就跨会话记住了：

- 记忆的**索引**（标题 + 一句话）常驻模型上下文；**正文**只在 agent 主动检索时才进入
- 在**设置 → 记忆**里可审阅、删除、或把某条设为「常驻」（常驻会把正文每轮都发给模型，默认关）
- 存放于 `memory.jsonl`，删除是追加墓碑，原文仍可审计

## 4. 命令速查

| 命令 | 触发词 | 作用 |
|---|---|---|
| `trans` | 翻译 · translate · fy | 翻译文本 |
| `find_file` | 找文件 · find · 搜索 · locate | 系统索引搜索，返回路径 |
| `grep` | 搜索内容 · grep | 在文件**内容**里搜，返回 `路径:行号` |
| `file_read` | 读文件 · read · cat | 读文件（大文件可只读行区间） |
| `file_list` | 列目录 · ls · dir | 列目录 |
| `file_write` | 写文件 · write | 写入/覆盖（覆盖已存在需批准） |
| `file_edit` | 编辑 · edit | 精确替换某段文字（改一行不必重写整份） |
| `file_rm` | 删文件 · rm · del | 删除（**恒需批准**） |
| `office_read` | 读文档 · office | 提取 docx/xlsx/pdf 文本 |
| `clipboard` | 剪贴板 · clip · cb | 剪贴板历史 / 语义召回 |
| `bash` | 执行 · run · sh | 执行 shell（**每次需批准**，默认禁网） |
| `web_search` | 联网搜索 · search | DuckDuckGo（**默认关闭**，开启后每次仍需批准） |
| `remember` / `recall` / `forget` | 记住 / 回忆 / 忘记 | 长期记忆 |
| `ask` | 提问 | agent 向你反问以澄清 |
| `memory` | 记忆列表 | 浏览全部记忆（agent 不可见） |

**agent 可调用的工具**：上表中除 `trans`、`clipboard`、`memory` 外的多数命令。
不在白名单内的工具一律拒绝执行（防模型「幻觉调用」）。

## 5. 安全边界（请知悉）

cTools 按「**远端模型不可信**」设计：

- **文件有界**：文件工具只作用于你设定的 `file_roots`；路径经词法 + realpath 双重校验，`../` 与 symlink 逃逸都会被拒
- **写操作要批准**：写/删/`bash` 每次弹批准；agent **没有免批通道**，即使它自称已获授权
- **剪贴板不外传**：剪贴板的语义召回只走你指定的**本地模型别名**；且它不是 agent 工具，agent 碰不到
- **默认无网络**：`web_search` 默认关闭；`bash` 默认经 OS 沙箱（`sandbox-exec`）**禁网**，沙箱不可用时**拒绝执行**而非降级
- **全量留痕**：每次对话以事件流完整落盘（谁说的、模型回了什么、调了哪些工具、参数与结果、你的批准/拒绝），压缩只影响展示、不删审计原文

## 6. 数据与备份

配置与数据都在 `~/Library/Application Support/cTools/`：

| 文件 | 内容 |
|---|---|
| `config.json` | 应用配置（含 `schemaVersion`，升级时自动迁移） |
| `gateway.yaml` | **网关配置**（providers / aliases）；首次运行会从你既有的 gw 配置迁移 |
| `gateway.log` | 网关进程输出（排障用） |
| `sessions/` | 会话事件流（JSONL，每行一个事件） |
| `memory.jsonl` + `MEMORY.md` | 长期记忆（索引页为生成物，手改会被覆盖） |
| `clipboard.jsonl` | 剪贴板历史 |
| `saves.json` | `/save` 沉淀的模板 |
| `spill/` | 超长工具结果的外置全文（agent 可回取） |

**备份**：整体拷贝该目录即可。**迁移到新机器**：连同 `gateway.yaml` 一起拷过去。

## 7. 常见问题

**命令提示「连不上本地模型网关」？**
网关没在运行。检查设置 → Gateway 的状态；点「重启」或「立即托管启动」。若提示「尚未配置模型上游」，走第 2.1 节配一个上游。

**设置里改了网关地址后全都不好用了？**
连接地址（`gatewayUrl`/`adminUrl`）默认 `127.0.0.1:8080/8081` 就是正确值，收在「连接（高级）」里。填错会导致命令与对话全部不可用——改回默认即可。

**`api_key_env` 填了但报鉴权失败？**
见第 2.1 节的说明：从访达启动的 app 读不到 `~/.zshrc` 里的变量，需要 `launchctl setenv`，或改用本机 Ollama。

**agent 说文件被拒绝？**
路径不在 `file_roots` 里。去设置 → 偏好补上目录。

**想让它更私密？**
设置 → 模型 → 「剪贴板召回模型（本地）」指向一个本地模型别名；这样剪贴板语义召回完全不经过远端。

**怎么彻底卸载？**
删掉 `cTools.app`，再删 `~/Library/Application Support/cTools/`（含全部会话与记忆）。
